# Sistema Integral de Gestión para Restaurantes
Patio El Olvidado

## Objetivo
Digitalizar y automatizar las operaciones del restaurante mediante un sistema web integral.

## Problemas actuales
- Gestión manual de pedidos
- Gestión manual de clientes
- Control manual de empleados
- Pagos y caja sin centralización
- Ausencia de historial de clientes
- Dificultad para obtener reportes

## Beneficios esperados
- Reducción de errores humanos
- Mejora de la eficiencia operativa
- Control financiero centralizado
- Fidelización de clientes
- Mejor experiencia para empleados y clientes
